# PlayNet

**▶ 플레이: https://street-kdh.github.io/PlayNet/**

설치도 가입도 없이, 링크 하나로 친구들과 즐기는 보드게임.

- 🔪 **마피아** (4~12인) — 밤이 되면, 누군가는 사라진다.
- 🎭 **라이어 게임** (3~10인) — 제시어를 모르는 단 한 사람을 찾아라.
- 🎤 **예능 퀴즈쇼** (2~12인) — AI 사회자가 진행하는 한 회짜리 예능 퀴즈! 초성·인물·노래 제목·사자성어 릴레이·속담·넌센스, 꼴찌는 벌칙.
  🎙️ 음성 모드를 켜면 내 차례에 폰이 문제를 읽어 주고, 말로 답하면 알아듣고 딩동댕·땡 소리를 내요 (크롬·엣지·사파리).

닉네임을 정하고 게임을 골라 방을 만든 뒤, 위쪽 방 코드를 눌러 초대 링크를 친구에게 보내면 됩니다.
인원이 모자라면 대기실에서 **🤖 부족한 인원 AI로 채우기**를 켜세요. 혼자서도 AI와 바로 한 판 할 수 있고,
친구가 들어오면 AI가 자리를 비켜 줍니다.

> 이 저장소는 GitHub Pages로 공개되는 **화면(정적 파일)** 입니다. 게임 진행은 별도로 운영되는 게임 서버가 담당하며,
> 서버가 꺼져 있으면 화면에 "서버에 연결할 수 없어요"라는 안내가 표시됩니다.
